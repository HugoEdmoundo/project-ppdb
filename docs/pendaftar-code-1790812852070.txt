TIU wajib dari komputer desktop/laptop Windows atau macOS dengan Safe Exam Browser; ponsel/tablet tidak didukung. Panduan instalasi dan penggunaan disediakan sebelum hari ujian. Setiap pendaftar hanya mendapat satu attempt; tidak ada retake setelah selesai atau waktu habis. Jawaban disimpan otomatis selama ujian.
Jika koneksi terputus, login kembali dan buka TIU untuk melanjutkan attempt yang sama melalui SEB. Jawaban yang tersimpan di server dipulihkan agar peserta melanjutkan dari jawaban terakhir; ini bukan attempt baru. Timer tetap berjalan selama koneksi terputus dan tidak di-reset. Jika waktu habis sebelum peserta tersambung kembali, jawaban tersimpan dikumpulkan dan dinilai otomatis. Kendala listrik/perangkat harus segera dilaporkan ke panitia untuk ditinjau.
Setelah webhook Apps Script berhasil memasukkan nilai TIU ke sistem, peserta menerima notifikasi WhatsApp dan dapat melihat nilai serta tahapan berikutnya di dashboard.
