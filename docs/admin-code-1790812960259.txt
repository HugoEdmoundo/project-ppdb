PENANGANAN ADMIN UNTUK PENGECUALIAN
- Webhook pembayaran duplikat tidak boleh menggandakan transaksi atau hitungan kuota.
- Pembayaran sukses yang terlambat setelah tagihan dibatalkan karena kuota penuh ditandai untuk pemeriksaan admin; jangan pindahkan pendaftar otomatis.
- Jika sinkronisasi soal gagal/tidak didukung, paket soal valid terakhir tetap digunakan dan admin mendapat pesan kesalahan. Tidak ada tahap publish manual.
- Dashboard konfigurasi menampilkan status dan waktu sinkronisasi terakhir agar admin tahu apakah perubahan Google Form sudah masuk.
- Jika peserta melaporkan koneksi putus, cari attempt aktifnya. Jawaban otomatis tersimpan di server; setelah koneksi pulih peserta resume attempt yang sama melalui SEB dan jawaban tersimpan dipulihkan. Jangan membuat attempt tambahan atau mengubah nilai diam-diam. Timer tetap berjalan.
- Arsip/dossier serta unduhan hanya untuk admin dengan izin khusus; akses sensitif harus dapat diaudit.
